# Superstore Performance Dashboard

An interactive Tableau dashboard built on synthetic superstore data. It highlights top KPIs and the relationship between sales and profitability through custom charts and a layout designed to be read without a walkthrough.

- **Live dashboard:** [Tableau Public](https://public.tableau.com/views/SuperstorePerformanceDashboard_17752568881510/SuperstorePerformanceDashboard)
- **Case study:** [grantjape.com/work/superstore-dashboard.html](https://grantjape.com/work/superstore-dashboard.html)

The workbook itself lives on Tableau Public; this folder holds its write-up.
