Superstore performance dashboard

A dashboard is only useful if someone can find their answer without a walkthrough. This one puts the top KPIs first, then shows how sales relate to profitability, using custom charts on synthetic superstore data.

Open on Tableau Public ↗

Interactive: filter and hover directly in the dashboard. If it doesn't load, open it on Tableau Public.

Design choices

  • KPIs first. The headline numbers sit at the top, so the most common question is answered before any scrolling.
  • One relationship per chart. Sales against profitability gets its own view, rather than sharing a crowded chart with other measures.
  • Custom charts where defaults fall short. Built in Tableau with layouts designed for this data, not the default templates.
